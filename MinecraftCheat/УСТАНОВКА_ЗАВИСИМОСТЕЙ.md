# 📦 Установка зависимостей для VasyCheat

## Шаг 1 — Visual Studio 2022 (Community, бесплатно)

1. Скачай: https://visualstudio.microsoft.com/vs/community/
2. При установке **обязательно** поставь галочку:
   - ✅ **Desktop development with C++**
3. Установка займёт ~5–10 ГБ

---

## Шаг 2 — CMake

1. Скачай: https://cmake.org/download/  
   → Выбери **Windows x64 Installer** (`.msi`)
2. При установке: ✅ **Add CMake to system PATH for all users**
3. Проверь: открой PowerShell → `cmake --version`

---

## Шаг 3 — Git

1. Скачай: https://git-scm.com/download/win
2. Установка по умолчанию (Next → Next → Install)
3. Проверь: `git --version`

---

## Шаг 4 — JDK 8 (нужен только jni.h)

> Minecraft 1.12.2 работает на Java 8, поэтому берём JDK 8.

1. Скачай: https://adoptium.net/temurin/releases/?version=8&os=windows&arch=x64&package=jdk
   → `OpenJDK8U-jdk_x64_windows_hotspot_*.msi`
2. Установи, при установке включи **"Set JAVA_HOME variable"**
3. Проверь: `echo $env:JAVA_HOME` (должен вывести путь к JDK)

**ИЛИ вручную задать JAVA_HOME:**
- Правой кнопкой на "Этот компьютер" → Свойства
- Дополнительные параметры системы → Переменные среды
- Создай новую системную переменную:
  - Имя: `JAVA_HOME`
  - Значение: `C:\Program Files\Eclipse Adoptium\jdk-8.0.xxx.xx-hotspot`

---

## Шаг 5 — Сборка

После установки всего выше:

```bat
cd "C:\Users\PC\Desktop\Легитка вась\MinecraftCheat"
build.bat
```

**Первая сборка скачает ImGui и MinHook из GitHub** (~20 МБ)  
и соберёт `VasyCheat.dll` + `Injector.exe` в папку `БИЛДЫ\`

---

## Частые проблемы

| Ошибка | Решение |
|---|---|
| `cmake не является внутренней командой` | Перезапусти PowerShell/cmd после установки CMake |
| `jni.h: No such file or directory` | Задай `JAVA_HOME` (Шаг 4) |
| `Cannot open source file "MinHook.h"` | Нет интернета для FetchContent — проверь соединение |
| Инжектор: `OpenProcess failed` | Запусти `Injector.exe` **от Администратора** |
| Класс `bib` не найден через JNI | Обфускация отличается — смотри README.md раздел маппингов |
